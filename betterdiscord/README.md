# ThemeVideoBackground for BetterDiscord

BetterDiscord plugin for video backgrounds in themes.

## Install

1. Copy `ThemeVideoBackground.plugin.js` into your BetterDiscord plugins folder:

```text
%AppData%/BetterDiscord/plugins
```

2. Enable `ThemeVideoBackground` in BetterDiscord plugins.
3. Use a theme that defines the video CSS variables.

## Notes

- Public direct MP4 URLs are recommended for shared themes.
- Local `file:///` paths are only useful for private themes on your own computer.
- The plugin does not force transparency. The theme controls all visuals.

See `DOCS.md` for theme author documentation.
